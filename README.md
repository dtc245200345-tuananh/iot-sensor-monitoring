
# IoT Sensor Monitoring System

## 1. Giới thiệu
Hệ thống giám sát cảm biến IoT được xây dựng trong khuôn khổ học phần Phát triển ứng dụng phân tán.

## 2. Công nghệ sử dụng
- C#
- .NET 10
- ASP.NET Core Minimal API
- RabbitMQ
- Database (sẽ lựa chọn)
- Docker
- Git và GitHub

## 3. Chức năng chính
- Đăng ký cảm biến.
- Tiếp nhận dữ liệu đo.
- Xử lý dữ liệu thông qua RabbitMQ.
- Lưu trữ dữ liệu cảm biến.
- Kiểm tra ngưỡng cảnh báo.
- Gửi cảnh báo realtime.
- Tra cứu dữ liệu và lịch sử đo.

## 4. Tiến độ thực hiện
Đang chuẩn bị môi trường phát triển.
